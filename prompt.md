# Задача: мобильное приложение nabzAI (Flutter)

## Контекст
nabzAI — ИИ-помощник для здоровья. Пользователь фотографирует бланк анализа и получает понятное объяснение на таджикском или русском, описывает жалобы и узнаёт срочность и к какому врачу идти, видит шаги и пульс, делится данными с врачом. Приложение НЕ ставит диагноз, это подсказки и оценка срочности.

Бэкенд готов. OpenAPI: http://localhost:3001/docs-json (если путь другой — найди его через http://localhost:3001/docs). Используй схему как единственный источник правды для моделей и эндпоинтов, ничего не выдумывай. Если чего-то не хватает в API — составь список и сообщи мне, не делай обходных решений.

Сначала покажи план: структуру папок, список экранов, навигацию, выбранные пакеты и дизайн-систему. Жди моего подтверждения. Потом делай по шагам, после каждого шага `flutter analyze` без ошибок и приложение запускается.

## Главное требование: дизайн
Приложение должно быть очень красивым, элегантным, спокойным и максимально понятным. Пользователи — от молодёжи до пожилых людей, многие без опыта с медицинскими приложениями. Человек, открывший приложение впервые, должен без подсказок понять, что делать.

### Характер
- Спокойное, тёплое, доверительное. Как хороший врач: уверенно, без паники, без канцелярита.
- Не «больничное»: никакого холодного голубого, крестов, стерильности.
- Никакого шаблонного Material-вида: свои компоненты, своя типографика, свои отступы.

### Визуальная система
- **Фон:** тёплый молочный (не чисто белый). Тёмная тема — глубокий тёплый графит, не чёрный.
- **Основной цвет бренда:** глубокий бирюзово-изумрудный. Один акцент, используется экономно.
- **Семантика срочности — отдельная палитра**, не пересекается с брендом: спокойный зелёный, тёплый янтарный, приглушённый красный. Красный не кричащий, но однозначный. Срочность никогда не передаётся только цветом: всегда ещё иконка и текст.
- **Типографика:** шрифт с полной поддержкой таджикской кириллицы (ҳ ҷ қ ғ ӣ ӯ и заглавные). Обязательно проверь рендер этих букв, на экране дизайн-системы выведи строку «Ҳаёт, ҷон, қалб, ғам, дӯст, шумо ӣ» во всех начертаниях. Крупный выразительный заголовочный шрифт + очень читаемый текстовый. Базовый размер текста не меньше 16, поддержка системного увеличения шрифта без поломки вёрстки.
- **Фирменный мотив — линия пульса.** Тонкая плавная линия, как на кардиомониторе, но мягкая и живая. Используй её в сплэше, на экране обработки анализа (линия «бьётся», пока идёт распознавание), в пустых состояниях, в логотипе на экране входа. Это главная визуальная фишка, не перегружай ей остальные экраны.
- **Формы:** крупные скругления, мягкие тени или вообще без теней (разделение цветом плоскостей), много воздуха.
- **Анимации:** плавные и короткие (200–400 мс), осмысленные: переходы между шагами, раскрытие карточек, появление результата. Лёгкая вибрация (haptics) на важных действиях. Уважай системную настройку «уменьшить движение».
- **Иконки:** один набор в одном стиле (линейные, скруглённые).

### Понятность — правила
- На каждом экране одно главное действие, крупная кнопка внизу в зоне большого пальца.
- Формы — по одному вопросу на экран, с прогрессом сверху.
- Никаких медицинских терминов без пояснения простыми словами.
- Каждый показатель анализа — карточка с визуальной шкалой: где норма, где значение пользователя. Понять «хорошо или плохо» можно за секунду, не читая цифры.
- Все пустые состояния, загрузки (скелетоны, не спиннеры), ошибки и отсутствие интернета продуманы и красиво оформлены, с понятным текстом и действием.
- Зоны нажатия не меньше 48×48, контраст по WCAG AA.

## Технологии
- Flutter stable, Dart 3, null safety.
- Архитектура feature-first + слои data / domain / presentation.
- flutter_bloc (BLoC/Cubit), go_router, get_it.
- dio: интерсептор авторизации, автоматический refresh токена через `/auth/refresh` с очередью параллельных запросов, единая обработка ошибок.
- Модели по OpenAPI (freezed + json_serializable или openapi_generator — предложи вариант).
- flutter_secure_storage для токенов.
- Локализация через ARB: таджикский (по умолчанию) и русский, переключение в настройках без перезапуска. Все строки только через локализацию. Помечай таджикские строки комментарием, что их проверит носитель языка.
- Пакет `health` для шагов и пульса (Apple Health, Health Connect).
- firebase_messaging для push (с заглушкой, если Firebase не настроен).
- camera / image_picker, file_picker (PDF), fl_chart, qr_flutter, share_plus, url_launcher.
- Базовый URL и флаги в конфиге окружений (dev/prod).

## Экраны и сценарии

### 1. Старт
- Сплэш с анимированной линией пульса и логотипом nabzAI.
- Онбординг 3 экрана: что умеет приложение, как работает, важное предупреждение «это не диагноз, решение принимает врач». Иллюстрации в фирменном стиле (линия пульса, простые формы), без стоковых картинок.
- Согласие на обработку данных — отдельный экран, понятный текст, чекбокс.

### 2. Вход
- Телефон с маской +992, крупные цифры.
- OTP: 6 ячеек, автоподстановка кода из SMS (Android SMS Retriever / iOS one-time-code), таймер повторной отправки.

### 3. Настройка профиля (первый вход)
- Пошаговый мастер, одиты н вопрос на экран: имя, пол, дата рождения (удобный выбор, не календарь с листанием лет), рост и вес (необязательно), язык.
- Затем необязательный шаг медкарты: хронические болезни, лекарства, аллергии — можно пропустить.

### 4. Главная
- Приветствие по имени и времени суток.
- Карточка «Сегодня»: шаги и пульс (или приглашение подключить данные).
- Карточка последнего анализа: статус (обрабатывается / нужна проверка / готово) и срочность.
- Два крупных главных действия: «Загрузить анализ» и «Что беспокоит?».
- Нижняя навигация максимум из 4 пунктов: Главная, Анализы, Активность, Профиль.

### 5. Загрузка анализа
- Выбор: камера, галерея, PDF.
- Камера с рамкой-подсказкой для бланка и советами (ровно, без бликов).
- **Экран скрытия личных данных:** пользователь закрашивает прямоугольниками ФИО, дату рождения и другие личные данные. По умолчанию предложи закрыть верхнюю часть бланка, пользователь двигает и меняет размер. Объясни простым текстом, зачем это. Координаты уходят в API как `redactionRegions` (относительные 0..1, с номером страницы для PDF). Сверь формат со схемой API.
- Загрузка с прогрессом.

### 6. Обработка
- Экран с «бьющейся» линией пульса и сменяющимися понятными статусами.
- Статус получать через push и polling `/me/labs/reports/{id}` как запасной вариант.
- Можно свернуть и вернуться позже, на главной будет виден статус.

### 7. Проверка распознанных значений
- Список показателей: название, значение, единицы. Каждое можно исправить крупным полем ввода.
- Показатели, в которых система не уверена, подсвечены (если API отдаёт уверенность; если нет — добавь в список недостающего).
- Рядом кнопка посмотреть исходное фото (через signed URL).
- Кнопка «Всё верно» отправляет `PUT /me/labs/reports/{id}/results`.

### 8. Результат анализа
- Сверху большая карточка срочности: цвет + иконка + одна фраза («Всё в порядке», «Стоит показаться врачу в ближайшее время», «Обратитесь к врачу срочно») + к какому специалисту.
- Объяснение простым языком, разбитое на короткие абзацы.
- Карточки показателей с визуальной шкалой нормы. Нажатие — подробнее и переход к истории показателя.
- Всегда видимый дисклеймер, ненавязчиво.
- Кнопка «Поделиться с врачом».

### 9. Анализы и история
- Список всех анализов по датам со статусами.
- Экран показателя: график по `/me/labs/analytes/{code}/history` с полосой нормы на фоне, понятные подписи.

### 10. Жалобы
- Чат в спокойном стиле: вопросы ассистента, быстрые ответы-чипы, где возможно, плюс свободный ввод.
- Прогресс опроса.
- Итог: карточка срочности и специалиста, краткое резюме.
- **Экстренный экран:** если API вернул красный флаг — отдельный полноэкранный экран, спокойный, но однозначный, с огромной кнопкой звонка в скорую (номер из конфига) и короткими инструкциями. Никакого продолжения чата.

### 11. Активность
- Экран подключения: зачем нужен доступ, затем системный запрос разрешений.
- Шаги и пульс за неделю и месяц, красивые графики.
- Синхронизация в фоне через `POST /me/metrics/daily`: при открытии приложения и периодически, без дублей.
- Если данных пульса нет (нет часов или браслета) — понятное пустое состояние.

### 12. Поделиться с врачом
- Выбор, что показать (анализы, жалобы, активность) и на сколько (1 день, 7 дней).
- Результат: QR-код крупно, ссылка, системное «Поделиться».
- Список активных ссылок, отзыв одной кнопкой.

### 13. Профиль и настройки
- Профиль, медкарта (CRUD), язык, тема (светлая/тёмная/системная), уведомления, выход.

### 14. Push
- Регистрация токена через `/me/push-tokens` после входа, удаление при выходе.
- Нажатие на уведомление открывает нужный отчёт.

## Приватность
- Никаких медицинских и личных данных в логах, аналитике и текстах уведомлений.
- Токены только в secure storage.
- На экранах с результатами анализов — опционально запрет скриншотов на Android (флаг в конфиге).

## Критерии готовности
- `flutter analyze` без ошибок, приложение собирается под iOS и Android.
- Полный сценарий на реальном бэкенде: вход → профиль → загрузка анализа → проверка → результат → история → жалоба → активность → ссылка для врача.
- Все строки на таджикском и русском, таджикские буквы корректно отображаются.
- Светлая и тёмная темы, системное увеличение шрифта не ломает экраны.
- Unit-тесты для блоков авторизации и загрузки анализа, виджет-тесты для карточки срочности и шкалы нормы.
